# Sales Week — Outreach Templates

## Daily cadence
- **5 personalized messages per day** (Mon–Fri = 25/week toward 100 total)
- Lead with the **demo link**, not pricing
- Log every send in the [sales tracker](/sales)

---

## Primary opening message

Use for prospects with a personalized demo (Week 1: 5 businesses):

```
Hi [First Name] — I built a quick AI receptionist demo using [Company Name] so you can hear how it would handle a missed customer call. Want me to send it over?

https://[your-domain]/demo/[slug]
```

### Example — ACExperts

```
Hi Landon — I built a quick AI receptionist demo using ACExperts so you can hear how it would handle a missed customer call. Want me to send it over?

https://[your-domain]/demo/acexperts
```

---

## Follow-up (48 hours, no reply)

```
Hi [First Name] — quick bump on the Ava demo I built for [Company Name]. Takes 30 seconds: tap "Call Ava" and pretend you're a customer with an emergency. No signup needed.

[demo link]
```

---

## Follow-up (they opened demo but didn't call)

```
Hi [First Name] — saw you checked out the demo. The "Call Ava" button lets you hear exactly how a missed after-hours call would go for [Company Name]. Worth 30 seconds if you're losing calls on jobs.
```

---

## Follow-up (they called Ava, no reply)

```
Hi [First Name] — glad you tried the demo. If you want to run a 14-day pilot on your actual number: $250 setup, $299/month after, 300 minutes included, cancel anytime. Happy to walk through it on a 10-minute call.
```

---

## What NOT to say

- Don't lead with "AI-powered conversational agent"
- Don't explain ElevenLabs, LLMs, or voice synthesis
- Don't send a feature list or pricing deck as the first message
- Don't link to the generic homepage — always use the personalized demo
